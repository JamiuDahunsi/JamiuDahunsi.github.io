# Jamiu Dahunsi - Personal Portfolio Website

This repository powers the official personal website of **Jamiu Dahunsi**, hosted live on GitHub Pages at:
👉 **[https://jamiudahunsi.github.io](https://jamiudahunsi.github.io)**

## About

Jamiu Dahunsi is a Cloud, Network Security, and DevOps Engineer pursuing a Master of Science in Electrical and Computer Engineering at **Carnegie Mellon University**. 

This portfolio showcases enterprise cloud architectures, network automation pipelines, certifications, and research projects across Microsoft Azure, AWS, and hybrid infrastructures.

## Tech Stack

* **Frontend:** Clean semantic HTML5, modern CSS3 (Custom Variables, Flexbox, CSS Grid), Vanilla JavaScript (ES6+).
* **Hosting:** GitHub Pages (automatic deployment via `main` branch).
* **Performance:** Fast, dependency-free, responsive across all screen sizes.
* **Features:** Dark/Light theme toggle, interactive mobile navigation, direct CV download, and project deep-dives.

## Local Preview

To view the website locally, open `index.html` in any web browser or serve it using Python:

```bash
# Serve locally on port 8080
python -m http.server 8080
```
Then visit `http://localhost:8080`.
